# YouTube Offline 0.5.22

- Novo navegador integrado para abrir a página, reproduzir o vídeo e identificar URLs de mídia recebidas realmente pelo navegador.
- Detecta vídeo, áudio, HLS e DASH pelos cabeçalhos HTTP e por fontes HTML5.
- Uma fonte selecionada pelo usuário pode ser baixada por transporte HTTP/FFmpeg independente do yt-dlp; o yt-dlp permanece como alternativa.
- Recursos HTTP só são classificados como candidatos quando a resposta é bem-sucedida.
- Preserva cancelamento, biblioteca offline, extração de playlists e sessões opcionais escolhidas pelo usuário.
- CAPTCHA, autenticação e DRM continuam sujeitos aos controles da plataforma e não são contornados automaticamente.
- Testes automatizados de detecção e validações Windows.
